# Noto Sans SC, name subset

`NotoSansSC-name-subset.woff2` is a subset of Noto Sans CJK SC (variable weight, version 2.004) that holds only the 3 characters of the wordmark on the home page: 欧宁睿. It was made with `pyftsubset` from fontTools.
